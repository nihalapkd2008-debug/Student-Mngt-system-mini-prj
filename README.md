# 📚 Student Management System

A simple and efficient Django web application to manage student records for educational institutions.

![Student List](https://github.com/user-attachments/assets/8a0adb42-e0cb-4e07-9049-f57de604f1ea)

---

## ✨ Features

- 📋 **View Students** - Display all enrolled students in a table format
- 🔍 **Search** - Search students by Name, Class, Phone, or Email
- ➕ **Add Student** - Easily add new student records
- 🗑️ **Delete** - Remove student records with one click
- 📱 **Responsive** - Works on all devices
